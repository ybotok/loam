# payment-service — capability spec

## Capabilities
- **Authorize payment** — reserve funds for an order. `POST /payments` (see `openapi.yaml`).
- **Capture payment** — settle a previously authorized payment. `POST /payments/{id}/capture`.

## Owns
- Payment aggregate: `id`, `orderId`, `amount`, `status`.

## Depends on
- `kafka` — emits `PaymentAuthorized`.
- `payment-split-service` — optional; used when a payment is split (FEAT-101).
